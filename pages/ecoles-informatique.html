DOMAINE 1 — ÉCOLES

OÙ ÉTUDIER L'INFORMATIQUE ET LE NUMÉRIQUE ?

Pour chaque spécialité, les écoles marocaines puis françaises accessibles après une classe préparatoire, classées par ordre de pertinence.

Cycle ingénieur : 5 ans après le bac, ou 3 ans après une classe préparatoire (CPGE) via un concours.

Comment lire le classement : il n'existe pas de classement officiel par spécialité. L'ordre (1, 2, 3) est indicatif : adéquation de l'école avec la spécialité, puis réputation dans le domaine. Concours : le CNC est marocain (CPGE marocaines) ; en France, le CC INP, Mines-Ponts et Mines-Télécom concernent surtout les filières MP/PC/PSI. Centrale-Supélec est une banque d'épreuves pour les filières MP/PC/PSI. Les intitulés de filières et les modalités d'admission évoluent : vérifiez-les sur le site de chaque école.
